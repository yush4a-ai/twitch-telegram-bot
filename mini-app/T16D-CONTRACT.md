# T16d: добровольное test-only ознакомление — локальный контракт

Дата: 2026-10-01. Основание: `mini-app/IMPLEMENTATION-ADDENDUM.md`.

- Viewer Plus на 7 суток выдаётся только после явного клика проверенного Telegram ID. Маршрут открыт лишь при том же серверном pinned-staging флаге и allowlist, что защищают mock checkout (`@TwitchSignalTestbot`; фактический main добавляет только owner ID). Локальный fixture использует отдельную временную БД и тестовые ID.
- Один ID может использовать ознакомление один раз. Запись trial и test grant создаются одной SQLite-транзакцией с `BEGIN IMMEDIATE`; повтор, replay и конкурирующие запросы возвращают исходный срок, не продлевая его. Активный иной Viewer Plus не расходует trial. Отзыв/expiry не дают второго grant.
- Источник grant — `test`, срок ровно 7×24 часа от server UTC. Нет платежа, Stars, карты, цены, checkout, автосписания или автоактивации при открытии приложения. После срока серверные Viewer Plus права исчезают, Free 50 и старые функции остаются.
- Экран доступа показывает кнопку только доступному allowlisted Free пользователю; после явного действия перечитывает серверное состояние. Ошибка/повтор не показываются как новый период.

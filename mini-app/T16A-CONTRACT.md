# T16a: папки Viewer Plus — локальный контракт

Дата: 2026-10-01. Основание: `mini-app/2026-10-01-scope-update.md`, основной spec и `mini-app/IMPLEMENTATION-ADDENDUM.md`. Это часть согласованной реализации, без изменения Free-прав.

- Папка принадлежит проверенному Telegram ID. Название 2–40 видимых символов, уникально у владельца без учёта регистра. Подписка может состоять максимум в одной папке; перенос атомарно заменяет прежнюю связь.
- Общий фильтр папки использует действующую модель Viewer Plus: категории и слова в названии. Если у стримера сохранён собственный фильтр, он целиком имеет приоритет над фильтром папки, включая намеренно пустой фильтр. Явный сброс личного фильтра возвращает наследование. Выключенные уведомления, доступ к подписке и текущий Plus имеют больший приоритет перед обоими фильтрами. Фильтр папки не отменяет тихие часы там, где они уже применяются; несовпадение go-live/raid с обещанием тихих часов проверяется отдельно в T12 по production-аудиту.
- Создание, переименование, удаление, настройка фильтра и перенос требуют текущий Viewer Plus. Сохранённые папки, связи и правила переживают expiry/refund; при неактивном Plus они только видны владельцу и не влияют на отправку. Удаление папки снимает связи, подписки и их собственные настройки остаются.
- API принимает только собственные идентификаторы; версия защищает одновременную правку папки в двух сессиях. Клиент не может присвоить чужую папку или чужую подписку. Старые bot-команды продолжают использовать тот же эффективный фильтр.
- Технический потолок хранения — 200 папок на владельца, по числу утверждённых подписок Viewer Plus. Это защита от бесконечного роста пустых папок, не новый рекламируемый тарифный предел.
- UI размещает папки в «Мои стримеры» и выбор папки в настройке конкретного стримера; Free видит подписки без применения платного правила. Пустое состояние, конфликт версии, ошибка сети и возвращение назад сохраняют честное состояние. При конфликте версия черновика не обновляется молча: сохранение отключено до явной загрузки текущих данных.
- RED/PASS: чужие папка/подписка, перенос, удаление без удаления подписки, наследование/приоритет, выключенный notify и expiry. Браузер: создание, перенос, правило, Back, 390/360 light/dark. Только временная БД и fake SDK; внешних отправок нет.

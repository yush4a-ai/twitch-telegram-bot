# T16b: личная история Viewer Plus — локальный контракт

Дата: 2026-10-01. Основание: утверждённый scope и T16b `mini-app/IMPLEMENTATION-ADDENDUM.md`. Это краткая лента собственных событий, не перенос HTML-отчётов из production-аудита.

- Источник — фактический терминальный результат персонального go-live, category-change или reminder send: `sent`, `suppressed`, `unknown`. Наблюдение Twitch, предварительный queue job, mock live, локальный пример поста и неподтверждённый Telegram ответ не выдаются за `sent`.
- Запись содержит только Telegram owner ID, тип, Twitch login, logical stream ID, ограниченное название категории при наличии, результат, время UTC и стабильный ключ для защиты от повтора. Видео, initData, токены, текст сообщения и Telegram message ID не хранятся.
- Подтверждённая отправка и терминальное состояние queue фиксируются в одной SQLite-транзакции; прямой legacy go-live путь пишет `sent` только после подтверждённого send и сохранения live state. Неизвестный исход не повторяется ради истории.
- Лента доступна только по подписанному Mini App ID с текущим Viewer Plus. После expiry данные до технической очистки остаются, но платный экран закрыт; прежние бесплатные функции и HTML-экспорт не затрагиваются. Страницы по 20, серверный keyset по собственному ID, без чужих событий.
- Записи старше 30 суток очищаются по server UTC в штатной технической очистке; это предел хранения, не обещание тарифа. UI различает три результата и показывает пустое/ошибку/следующую страницу без утверждения о просмотрах Telegram.
- RED/PASS: чужой доступ, fake live/delivery, идемпотентность, pagination, retention, expiry и оба пути go-live. Браузер: собственная лента, пустое состояние, 390/360 light/dark, Back. Только temp DB/fake sender, без внешних сообщений.

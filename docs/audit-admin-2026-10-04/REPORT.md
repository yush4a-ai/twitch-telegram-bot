## Проблемы

**P1 — табы «Доступы» недоступны с клавиатуры.** `panel.js:680-687` (живой), `#tab-active`/`#tab-history`. Замер: при фокусе на `#tab-active` ArrowRight/ArrowLeft/Home/End/Enter/Space не меняют ни `aria-selected`, ни видимость панели — только клик. Роль `tab` обещает клавиатурную навигацию, поэтому пользователь скринридера не откроет «Историю». Рекомендация: roving `tabindex` + `keydown` (стрелки, Home/End) + активация Enter/Space. В локальном `bot/admin_ui/panel.js` `keydown` и стрелки уже есть — достаточно развернуть.

**P2 — обрезка значения в карточке лимитов при 360px.** `panel.css` `.metric-grid.compact` / `.metric strong`, элемент `#limit-video` («Видео доступно с Plus»). Замер: бокс 101px, текст 121px → overflowX **+20px**, `overflow-wrap: normal`. Скриншот `shots/user-detail-360-limits.png`: «доступн**о**» срезано краем карточки. Рекомендация: `overflow-wrap: anywhere` для `.metric strong`/`.metric-label`; ниже 400px — одна колонка или кегль 1.125rem.

**P2 — диалог выдачи выше вьюпорта на телефоне.** `.admin-dialog` (`panel.css:153`). Замер: 360×780 — диалог 740px, `scrollHeight 846 > clientHeight 740`, submit bottom 842; 360×640 — 842; 390×740 — 822. Внутренний скролл есть, но кнопки без прокрутки не видны. Рекомендация: `.dialog-actions` → `position: sticky; bottom: 0`.

**P2 — таблицы без доступного имени.** Все 5 `table.data-table`: нет `caption`, `aria-label`, `aria-labelledby` (замер live DOM), хотя `h2` рядом есть, но связь не объявлена. Рекомендация: `aria-labelledby` на существующие `h2` — 5 правок.

**P3 — цели меньше 44×44.** `.button-quiet` «Выйти» 68×36 (`panel.css:65`); `.tab` 135×40 и 92×40 (`panel.css:127`); `.skip-link` 137×43.

**P3 — нет `prefers-color-scheme`.** `panel.css:4`, `index.html:6`. Замер: при light-схеме body остаётся `rgb(241,241,241)` на `rgb(23,23,23)`, токены те же — системная настройка игнорируется. Тёмная-only тема объявлена корректно.

**P3 — цвета вне токенов.** `panel.css:64` `#D6BCFF` (контраст 10.24:1 — PASS, но вне токена); `panel.css:154` `rgba(0,0,0,.6)`; `.nav-badge` `#2A0E12`; `.notice` `rgba(240,198,116,.08)`.

**P3 — `no-store` и полная перерисовка.** CSS и JS отдаются с `Cache-Control: no-store` — повторный визит всегда качает 13.2 КБ gzip. `panel.js:736` каждые 30 с вызывает `refresh()` с `replaceChildren` по всем таблицам.

**P3 — пустой `select` «Право».** Замер: `grantChoices: 0`, `hidden=false`, при `#grant-target` = «Получатель не выбран»; `fillGrantChoices` скрывает select лишь при отсутствии ручных прав, оставляя пустую строку.

## Проверено и корректно

- **Контраст:** 20 пар, минимум 6.19:1 (danger), все ≥ требуемого. Границы `--border` на `--surface` дают 1.35:1 (<3:1), но информацию не несут — семантику дают фон и текстовые метки; ложное срабатывание.
- **Фокус:** 2px solid `--accent`, offset 2px, на всех 9–11 фокусируемых элементах; skip-link первым.
- **Диалог:** фокус при открытии внутри, 13 Tab вперёд и назад — 0 выходов, Escape закрывает, фокус возвращается на `#grant-open`, `::modal` активен, фон затемнён. Ранее видимый «выход на 13-м шаге» — ложное срабатывание: Tab+Enter на «Выйти» уводил со страницы.
- **Разметка:** `lang="ru"`, `role="status" aria-live="polite"` для времени обновления, 3×`role="alert"`, `role="tablist"`+`aria-label`, `aria-controls`, `aria-selected`, 20/20 `th[scope]`, 11 `label` на 11 полей.
- **Мобильная раскладка:** таблицы → карточки через `data-label`, две колонки метрик, нижняя навигация 48px + safe-area.
- **Анимации:** 0 `transition`/`animation` вне блока `prefers-reduced-motion` (`panel.css:199`); `will-change` нет; переходов по layout-свойствам нет.

3. **Firefox/Safari** — аудит только Chromium.
4. **Живой контур ≠ репозиторий:** production отдаёт HTML 21855 Б / CSS 13545 Б / JS 29576 Б, локально — 22627 / 14165 / 36200 Б (локально уже есть `keydown`, `receipt`, «Выдать по ID»). Все находки — на живой версии; часть в репозитории уже исправлена.

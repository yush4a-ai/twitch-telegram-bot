# Mini App: уточнение интерфейса и Telegram safe areas — план

> Исполнение: один владелец реализации, последовательно через superpowers:executing-plans. Владелец уже прямо разрешил аудит и самостоятельные разумные исправления. Новое согласование визуального направления не требуется: сохраняем текущую систему. Перед работой дождаться завершения активного release другого чата в той же папке.

**Цель:** исправить взаимодействие с панелями Telegram и повысить ясность основных действий без смены структуры или бизнес-логики.
**Архитектура:** существующие vanilla HTML/CSS/JS, shared tokens/components и строгие API. Browser fixture только loopback с временной БД; никакого fixture на live маршруте.
**Спецификация:** AUDIT.md, Design Issue Map D01–D16; исходный запрос владельца attachment 79fa28bf-e920-488e-9220-9355b690e45d.

## Ограничения

- Одна ветка autonomous/twitchsignal-roadmap; сохранять старую работу и неподконтрольные файлы.
- Payment OFF, цены150/300, три способа сохранены, orders/invoices/grants/external POST из UI не появляются.
- Production/main/master/secrets, OAuth владельца и отправки реальным получателям не входят в задачу.
- Собственная палитра, системный шрифт, текущие роли, четыре раздела, история/HTML/export/legacy groups сохраняются.
- Полный gate только финального snapshot. Нативную проверку не заменять browser PASS.

## Единая система

Существующие semantic цвета сохраняются. Добавить токены ширины600px, пространства нижней навигации12px и типа/поверхностей там, где они повторяются. Шкала4/8/12/16/24. Primary48px, самостоятельные действия44px+. Активная навигация с подложкой; текст и иконка остаются. Границы групп16px, нижняя панель24px, без общего glass/blur. Input values400, labels600, body/system шрифт. Навигация поддерживает text200 с переносом, не уменьшает шрифт ради одной строки. Системные области адаптивные, не фиксированные59/47 в продукте.

## Фокус проверки

1. Два ненулевых inset-слоя и независимые поздние SDK события.
2. Маленький320px/короткий viewport, длинные RU/Latin данные, time input WebKit.
3. Начальный network error с повтором против401/403, где повтор не обходит вход.
4. Все способы остаются кликабельными и сохраняют честный OFF; read-only catalog диктует предупреждение.
5. Переход/проверка прав не показывает устаревший success другого состояния; черновики и back/focus сохраняются.

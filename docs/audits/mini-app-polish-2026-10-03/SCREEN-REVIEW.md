# Проверка экранов глазами нового пользователя

Это экспертная оценка работающего локального приложения, а не измерение поведения реальных пользователей. Критерий «понятно за 2–3 секунды» проверялся по заголовку, главному действию и объяснению результата. Рост конверсии не измерялся.

Для каждой строки проверены: где я; что можно сделать; зачем; следующий шаг; приоритет действия; конкурирующие элементы; термины; необходимые объяснения; последствия нажатия; необходимость догадываться. В таблице отмечены выводы и исключения. Точный набор кадров и состояния доступны в JSON-отчётах рядом с PNG.

| Экран / состояние | Где, что и зачем | Следующее действие и приоритет | Термины, последствия, оставшиеся вопросы |
|---|---|---|---|
| Первый вход / загрузка | Виден процесс проверки входа | Дождаться результата | Статус озвучивается; при сетевой ошибке есть повтор |
| Вход без Telegram / истёкший вход | Объяснено, почему приложение не открывается | Открыть из бота | Повтор по старой подписи не предлагается; приватные данные не показываются |
| Главная без подписок | Теперь явно названы Twitch, Telegram и уведомления | Одна синяя «Добавить стримера» | Исчез промежуточный пустой список; шагов до добавления 3 вместо 4 |
| Главная с эфирами | Имя, статус, категория и название разделены | «Смотреть» у конкретного эфира | Название в кавычках не выглядит системным предупреждением; живой статус остаётся с текстом и точкой |
| Главная без эфиров / устаревшие данные | Подписки сохранены, статус уточняется | Перейти к своим стримерам | Не обещаем, что стример точно офлайн при устаревших данных |
| Стримеры / большой список | Список отслеживаемых аккаунтов и уведомлений | Добавление primary, поиск и инструменты secondary | Колокольчик меняет уведомления, не удаляет подписку; подписи для screen reader сохранены |
| Поиск добавления / результат | Отдельная задача, ник или Twitch-ссылка | Ввод → добавить найденного | Результат привязан к имени; загрузка, пустой поиск, повтор и ошибка не маскируются |
| Карточка стримера | Настройки именно выбранной подписки | Уведомления, фильтры, папка, напоминание | Удаление требует подтверждения; отмена сохраняет подписку |
| Папки / правило папки | Группировка и общее правило | Создать/сохранить правило | Удаление папки не удаляет подписки; наследование и личное правило остаются различимыми |
| Фильтр категории / выбранные категории | Выбор эфиров, о которых сообщать | Выбрать и сохранить | При лимите или конфликте не показываем ложное сохранение; CAS сохранён |
| Напоминание / ошибка / завершено | Напоминание относится к стримеру | Настроить или отменить | Не подменяем результат отправки таймером в браузере |
| Видеопревью / Free / 5 мест | Показаны платность и число мест | Выбрать стримеров / заменить занятое место | Офлайн-стример занимает место; смена тарифа не выдаёт доступ локально |
| Профиль | Учётная запись и настройки | Открыть нужную строку | Тема, уведомления, поддержка и история сгруппированы; HTML-отчёт сохранён |

| Посты / стандартный вариант Free | Доступный формат сообщения | Настроить доступное, посмотреть пример | Нет нового paywall вокруг бесплатного поста |

| Оплата недоступна | Ограничение видно до списка способов | Можно проверить конкретный способ | Все три метода сохранены; известный OFF без бессмысленного повтора, сбой сети с повтором |
| Подписка / операции / детали заказа | Фактический доступ и источник операции | Проверить статус / историю | Тестовый и пробный доступ не названы оплаченной покупкой; нажатие не создаёт fake grant |

## Общие выводы

- IA: два режима и четыре раздела понятнее сохранять на месте. Перестановка разделов увеличила бы стоимость обучения опытного пользователя.
- UI: основная проблема была в компоновке Telegram и различимости состояния, а не в палитре. Системный шрифт и синий акцент сохранены; активная вкладка получила подложку.
- Onboarding: объяснение рядом с первой задачей заменяет отдельную презентацию. Новая пустая главная даёт действие сразу.
- Monetization: четыре блока пользы уже были сильной частью экрана. Улучшена честность доступности покупки; конверсию можно измерять только после подключения оплаты и согласованного исследования.
- Accessibility: проверяемые названия контролов, минимум 44px, контраст базовых текстовых пар ≥4.5:1, text200, видимый фокус, Tab/Shift+Tab и reduced motion. Полная сертификация WCAG и тест с нативным VoiceOver не заявляются.
- Microinteractions: сохранены короткие реакции на нажатие и блокировка повторного запроса; добавлены явное восстановление после сбоя и безопасное обновление сообщений. Постоянная анимация live не нужна.

# Персонаж: исправление по замечанию владельца

Источник: исходный маскот владельца и утверждённый концепт профиля. Built-in imagegen, режим edit/background-extraction, transparent_background=true. Сохранён полный персонаж с руками и волнами, удалены космос/подложка. Результат bot/mini_app_ui/mascot-cutout.png: RGBA1254×1254, alpha0–255,820165bytes. Исходный plus-mascot.png сохранён для тарифного баннера.

Промпт: сохранить узнаваемый фиолетовый объёмный маскот из исходника, воспроизвести вертикальный компактный силуэт из правой части профильной карточки концепта; удалить космический фон, круг, орбиты и тёмный ореол. Две вертикальные тёмные глаза с белыми бликами, фиолетовые руки, машущая левая, красный индикатор и две волны справа сверху. Весь силуэт на истинно прозрачном PNG, без текста/интерфейса/дополнительных элементов; предназначен для светлой сиреневой и графитовой карточки.

Маски CSS и круглое кадрирование сняты в профиле/главной/пустом состоянии. Главная повторяет крупную композицию концепта с заголовком, вынесенным персонажем, отдельным списком эфиров и переходом «Мои стримеры». Фиктивный общий статус уведомлений и offline-каталог не добавлены согласно предыдущему согласованию. Старый FINAL-* предшествует этой правке: новые доказательства CONCEPT-FINAL-*.

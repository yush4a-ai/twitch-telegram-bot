# Правки Mini App: проверка владельцем

Исправления опубликованы на тестовом боте, проверка после выкладки PASS. Вход: [@TwitchSignalTestbot](https://t.me/TwitchSignalTestbot) → «Приложение». При открытом старом окне закройте его и откройте приложение заново. Адрес shell: https://worker-staging-2f74.up.railway.app/app; личные данные доступны только из подтверждённого Telegram-входа.

## Что посмотреть

1. Главная и Профиль: полный персонаж без круглой подложки, светлая/тёмная тема. Переключатель ролей не должен попадать под кнопки Telegram. [Сверка с концептами](CONCEPT-COMPARISON.html), [все основные экраны](RESULT.html).
2. Стримеры: отдельные уведомления и избранное; «Только избранные»; поиск и возврат из карточки с сохранением позиции. Свайп раскрывает удаление, отдельное нажатие удаляет. «Отменить» возвращает подписку и настройки в течение 60 секунд, если лимит и связанные настройки не изменились.
3. Мой канал: «Проверить права» показывает ожидание и результат даже при прежних правах. Публикации и права отображаются отдельно. Фото канала только после проверки доступа.
4. Тарифы: «Зритель Plus» 150 ₽/месяц, «Стример Plus» 300 ₽/месяц, четыре блока преимуществ и отдельное «Подробнее о Plus». Оплата выключена; пробный доступ остаётся только у существующего разрешённого аккаунта. Демонстрации помечены как примеры, настоящие видеопримеры ещё не добавлены.
5. Профиль → «Отчёты об эфирах»: выберите существующую подписку/канал, настройте автоотчёт и краткий текст либо текст + HTML. Переключатель уведомлений независим; прежние получатели, условия доставки и HTML сохранены.

## Границы доказательств

RELEASE-chromium/report.json и RELEASE-webkit/report.json: по137 проверок, по41 снимку текущих компонентов на тестовых данных. Нет поддельного Telegram-входа, SDK, API-запросов или отправок. Задержки/ошибки, серверные ограничения и восстановление покрываются отдельными локальными тестами. Браузерная эмуляция не подтверждает iPhone/Android, клавиатуру, системные жесты, настоящий OAuth и реальные отправки. Меню — единственный отдельный сценарий, который владелец уже подтвердил на устройстве.

Обновление предназначено только для тестового бота. Production, реальные платежи и внешние получатели не менялись.

## 2. Что именно эти тесты доказывают

- Эксплойт-набор (`tests/test_stars_exploits.py`): повторное подтверждение не продлевает
  подписку; возврат не возвращает доступ; чужая транзакция и чужая сумма не выдают доступ;
  неоплаченный счёт перестаёт блокировать покупки; оплата по закрытому заказу зачитывается;
  сверка читает все страницы истории; переполнение реестра попыток не останавливает продажи.
- Провайдер звёзд: счёт-сообщение для бота и ссылка для мини-аппа; приём длинного
  идентификатора платежа (131 символ); восстановление оплаты по истории транзакций;
  отклонение чужого покупателя, суммы, валюты, повторного списания.
- Жизненный цикл платежа: один факт на транзакцию, один грант на заказ, повтор →
  `already_applied`; возврат отзывает только грант своего заказа; правки по замороженным
  условиям.
- Мини-апп: подпись initData (в т.ч. чужая, просроченная, с дублями), недоступность
  тестовых ручек, готовность способов по политике, переход на ссылку для оплаты.
- Platega: проверки подписи/статусов на фикстурах (реальный провайдер не вызывался).
- Права: наследование Streamer Plus → Viewer для замороженного получателя, истечение,
  разрывы цепочек.

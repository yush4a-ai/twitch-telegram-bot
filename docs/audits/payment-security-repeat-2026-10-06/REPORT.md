## Ключевые доказательства

- **Идемпотентность под конкуренцией (моя проба):** 50 одновременных применений одного платежа →
  `applied` 1 раз, `already_applied` 49, в базе ровно 1 факт оплаты и 1 период.
- **Оплата выключена = закрыто (моя проба):** при выключенной политике подготовка платежа
  отвечает «недоступно», заказов 0, счетов 0, доступов 0; даже при всех флагах без
  `BILLING_PUBLIC_STARS` счёт не создаётся.
- **Двойной тап (проверка темы E):** два одновременных запроса → ровно один заказ и один счёт.
- **Интерфейс не врёт про оплату:** пока сервер не подтвердил платёж, экран показывает
  «Ожидает оплаты» и «возможности не активны».
- **Чужие данные недоступны:** локальные проверки трёх пользователей — заказы, каналы,
  намерения, шаблоны и отчёты чужих людей дают отказ.
- **Тесты:** 109 платёжных и авторизационных (мой прогон) + 88 + 49 + 32 + 25/64/120/133/78
  (прогоны независимых проверок) — все зелёные, без пропусков.

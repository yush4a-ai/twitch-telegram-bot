# Аудит пользовательских текстов

Продолжение замечаний владельца к главной и подписке. Проверены все Python handlers, все верхние bot modules и все Mini App JS: 92 файла, 1525 русских строковых выражений, 41 длиннее160символов. Это инвентаризация источников, а не автоматическое доказательство качества каждого сообщения. Дополнительные длинные выражения оказались HTML-секциями сайта/admin/OAuth/кабинета и SQL schema с комментарием; пользовательских сплошных Telegram-описаний среди них нет.

| Поверхность | Решение и фактический результат |
|---|---|
| Первый вход / главная | Короткий заголовок, отдельные счётчики и live-блок; нет повторения бренда с картинки. Unknown не называется offline. |
| Тариф / активная подписка | Цена, статус и срок отдельно. Четыре блока из общего каталога вместо семи длинных bullet. Streamer включает все Viewer-возможности. |
| Оплата / поддержка | Продукт и цена отделены от выбора способов; Telegram/Platega названы прямо. PaymentOFF, отсутствие списания и автопродления видны. Контакты не придуманы. |
| Помощь / команды | Заголовки по задачам, отдельные условия импорта, тихих часов и бесплатных HTML-отчётов. Команды разделены по назначению. |
| Twitch / Telegram-канал | Нумерованные шаги, отдельные identity/сообщества/следующее действие. Сохранённое подключение не называется готовой публикацией. |
| Добавление / импорт / поиск / удаление | Действие, результат поиска/счётчики и последствия подтверждения разделены. Серверная мутация требует прежнего подтверждения. |
| Настройки стримера / тихие часы | Оповещения и отчёты разнесены; местное время в отдельном блоке, UTC и исключение рейдов сохранены. |
| Ручные / автоматические отчёты | Метрики выделены блоком; UTC, неизвестные фолловеры и неполные данные не скрыты. HTML и резервный экспорт сохранены. |
| Live / raid / category / reminders | Уже короткие сообщения с выделенными именами/цифрами. Смысл и путь доставки сохранены; media/runtime не менялись. |
| Mini App | Тариф уже использует четыре группы и раскрываемые подробности; профиль, помощь, отчёты и streamer flow имеют секции. Нового redesign нет. Восемнадцать исходников совпадают с проверенной браузерной версией. |
| Legal links / документы | Заголовки/списки и безопасный DOM уже есть. Юридический смысл и readiness не переписаны; реальные legal routes по-прежнему могут возвращать503 до заполнения данных владельцем. |

Короткие callback alerts и ошибки не оборачиваются в HTML: Telegram их не парсит. Пользовательские шаблоны, технические логи, исторические docs/tests/audits и экспорт не подвергались global replace.

## Предпросмотр

`http://127.0.0.1:8874/` — временный loopback static server, экспортирует только HTML и3одобренных PNG. Репозиторий/БД/секреты не раздаются. Сохранённый оригинал: `preview.html`; данные: `PREVIEW-CAPTIONS.json`; генератор: `preview.py`.

Перед публикацией нужен новый полный suite итогового clean commit, стандартный guarded staging deploy и проверка конкретного runtimeSHA/Testbot/прав. Старые и прерванные full runs его не заменяют.

## Остальные входы и ограничения

- `/start track_*`, `link_*`, `src_*`, `ref_*`, `tscommunity_*`: прежние parser/ownership/expiry. Track deep link сохраняет прямое добавление.
- Financial pre_checkout/successful/refunded updates: прежний BillingService, frozen order/beneficiary проверки; новая навигация не подтверждает оплату.
- chat_shared: existing complete_community_intent, channel-only, verified identity, can_post/admin, expiry/cancel. Возврат persistent Menu.
- chat_member/my_chat_member: прежний reconciliation существующих подключений.
- HTML build_report_html/answer_document/export + text summaries: сохраняются, новые платные права на них не вводятся.
- System MenuButton pinned staging: MenuButtonWebApp «Приложение» /app.
- Inline и ReplyKeyboard нельзя поставить одновременно в одном reply_markup: отдельная короткая подсказка с persistent Menu, затем единый home. Native расположение NOT TESTED.
- Старые callbacks остаются зарегистрированы; удаление лишних входов с первого экрана не отменяет функцию. Legacy togglepreview сохраняет отказ при отсутствии прав, а не включается обратно.
- Legacy /viewer остаётся глубже; import/auth/invite/myid/stats/health сохраняются командами. Новые group connections не предлагаются.
- Новый Add требует подтверждения, старые track/addfound сохраняют прежний контракт и atomic limit.
- Новый streamer flow переиспользует OAuth/community intents; Menu отменяет только собственный незавершённый intent, а не сохранённые данные.
- Telegram Plus и Mini App читают один catalog/subscription/first-release BillingService contract. OFF независимо от credentials; без provider POST/invoice/orders/grants.
- Support/legal только реальные Config/canonical ready; непроверенные legal не публикуются.

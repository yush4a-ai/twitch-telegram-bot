==================================================
ДОПОЛНЕНИЕ: ГЛАВНАЯ, ЦВЕТНЫЕ КНОПКИ И SMART HOME
==================================================

1. Переименовать основное действие:

НЕ:
«Добавить стримера»

А:
«➕ Добавить оповещения»

Это название использовать в новом Telegram home.


==================================================
ЦВЕТА КНОПОК
==================================================

Использовать актуальный Telegram Bot API button style.

Главная:

[ Открыть приложение ]
style = primary

[ ➕ Добавить оповещения ]
style = success

[ 🎥 Я стример ]
обычный/default style

[ Ещё ]
обычный/default style

Не красить все кнопки.

danger использовать только
для действительно опасных действий:

- удалить;
- отключить;
- отменить критическое действие,

если это уместно.

Не пытаться задавать произвольные HEX/RGB цвета.
Использовать только официальные Telegram styles.


==================================================
SMART HOME / ДИНАМИЧЕСКАЯ ГЛАВНАЯ
==================================================

Главное сообщение должно зависеть
от фактического состояния пользователя.

Не создавать разные разрозненные меню.
Использовать один Home builder,
который получает server-side state.


СОСТОЯНИЕ A — НОВЫЙ ПОЛЬЗОВАТЕЛЬ

У пользователя нет отслеживаемых стримеров
и нет подключённого broadcaster.

Показать фирменное изображение TwitchSignalBot.

Под ним коротко:

TwitchSignalBot

Следи за стримерами или подключи свой канал.

И четыре кнопки:

Открыть приложение
➕ Добавить оповещения
🎥 Я стример
Ещё


==================================================
СОСТОЯНИЕ B — УЖЕ ЕСТЬ ОПОВЕЩЕНИЯ
==================================================

Если пользователь уже отслеживает стримеров,
не обязательно показывать рекламный баннер.

Вместо него показать короткую полезную сводку.

Например:

TwitchSignalBot

Отслеживаешь: 8
Сейчас в эфире: 2

papapaver · GTA V
example · Just Chatting

Показывать максимум 2–3 live-стримера,
чтобы Home не становился длинным.

Если live больше:

«И ещё 4 в эфире»

Кнопки остаются те же.


==================================================
СОСТОЯНИЕ C — НИКТО НЕ В ЭФИРЕ
==================================================

Если подписки есть,
но никто сейчас не стримит:

TwitchSignalBot

Отслеживаешь: 8
Сейчас никто не в эфире.

Я сообщу, когда кто-нибудь начнёт стрим.

Не показывать пустые таблицы/технические статусы.


==================================================
СОСТОЯНИЕ D — ПОЛЬЗОВАТЕЛЬ ЕЩЁ И СТРИМЕР
==================================================

Если есть verified broadcaster,
можно добавить ОДНУ компактную строку:

«Твой Twitch подключён»

или, если publishing реально включён:

«Твой канал подключён · публикации включены»

Не превращать Home в streamer dashboard.

Подробности остаются внутри:
«🎥 Я стример».


==================================================
ОБНОВЛЕНИЕ SMART HOME
==================================================

Home state обновлять при:

- /start;
- нажатии persistent «Меню»;
- «На главную»;
- возврате из основных menu flows.

Не требуется постоянно редактировать Home
в фоне каждую минуту.

Live-уведомления остаются отдельной системой.

Это уменьшает:
- лишние Telegram edits;
- race conditions;
- API нагрузку;
- визуальный шум.


==================================================
ОДНО МЕНЮ-СООБЩЕНИЕ
==================================================

Где безопасно — редактировать текущее
home/menu message вместо отправки
нового сообщения на каждый callback.

Использовать editMessageText /
editMessageCaption /
editMessageMedia /
editMessageReplyMarkup
по типу текущего сообщения.

Если edit невозможен или сообщение устарело —
безопасно отправить новое Home.

Не ломать старые callbacks.


==================================================
БАННЕР
==================================================

Создать отдельный фирменный
TwitchSignalBot welcome banner.

Баннер нужен прежде всего:

- новому пользователю;
- пользователю без подписок.

Не генерировать изображение на каждый запрос.

Использовать заранее подготовленный
статический asset/file_id.

Для возвращающегося пользователя
предпочтительнее полезная текстовая сводка,
а не декоративная картинка.


==================================================
ТЕСТЫ
==================================================

RED→PASS:

- 0 subscriptions → welcome banner;
- subscriptions > 0 → smart summary;
- live=0 → спокойное empty состояние;
- live=1 → один streamer;
- live>3 → максимум 3 + «ещё N»;
- verified streamer → компактный streamer status;
- данные другого пользователя никогда
  не попадают в Home;
- Open App style primary;
- Add notifications style success;
- остальные основные кнопки default;
- меню не создаёт бесконечную цепочку сообщений;
- fallback при невозможности edit работает.

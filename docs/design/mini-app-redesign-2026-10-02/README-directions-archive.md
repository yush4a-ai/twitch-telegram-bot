## Находка для будущего плана

Сейчас `bot/streamer_community.py` требует для канала и `can_post_messages`, и `can_edit_messages`. В новом макете указано только право публикации. Официальная документация описывает `can_edit_messages` как право редактировать чужие сообщения, а `can_post_messages` разрешает удалять собственные исходящие сообщения с ограничениями `deleteMessage`. Код `live_post.py` редактирует собственные сообщения. Это основание пересмотреть избыточную проверку после выбора дизайна; реальный edit собственных постов с минимальными правами пока NOT TESTED. Код прав на этом этапе не изменён. Источники: [ChatMemberAdministrator](https://core.telegram.org/bots/api#chatmemberadministrator), [deleteMessage](https://core.telegram.org/bots/api#deletemessage).

Прежние группы, бесплатные права, HTML-отчёты, серверные entitlement checks и пять слотов сохраняются. Новые подключения канала, минимальное первое сообщение, menu compatibility, OAuth completion, защищённый инструмент владельца и все остальные экраны войдут в согласуемый план после выбора. Перенос расширенных отчётов, новая платность/retention и реальные оплаты остаются отдельным этапом.

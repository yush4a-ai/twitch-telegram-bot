# Повторяемые проверки отдельного предпросмотра

Это собственные браузерные проверки макета, не исполнитель разработки и не проверки работающего бота. Telegram, OAuth, API продукта и БД не вызываются.

- `build_portable.py` собирает один HTML и фиксирует SHA256 четырёх исходных файлов. Аватары встраиваются с MIME по фактическим байтам.
- `browser.cjs` проверяет Chromium/WebKit, действия, четыре экрана, размеры, темы, фокус и все текстовые подписи при увеличении до 200%.
- `async-focus.cjs` проверяет фокус во время ожидания, результата и пользовательского Tab в обоих движках.
- `text-navigation.cjs` проверяет реальные границы всех действий меню при тексте 200%, включая обрезание родительским контейнером.
- `plan-reflow.cjs` проверяет целый статус плана при тексте200 на профиле/подписке Free/Plus, в обеих темах и движках.
- `zoom.cjs` проверяет настоящий масштаб вкладки Chromium через `chrome.tabs.setZoom/getZoom`, контраст и фактический системный шрифт. Создаёт отдельный временный профиль и локальное дополнение только для localhost; глобальных установок нет.
- `portable.cjs` открывает HTML через file URL, ждёт декодирования картинок, проверяет навигацию и отсутствие HTTP-запросов.
- `state-capture.cjs` снимает две доски состояний через WebKit26.5. Итоговые картинки сверяются с DOM и проверяющим.
- `capture.cjs` снимает доски, видимые области и полный вертикальный контент. Для каждого снимка используется свежий процесс браузера. Изображения не склеиваются и не редактируются.

Рабочие копии проверок запускаются из `$env:TEMP` через установленный `playwright-skill/run.js`, в видимых браузерах. `PREVIEW_DIR` указывает эту папку макета. `CONCEPT_URL` задаёт локальный сервер для основной проверки, по умолчанию `http://127.0.0.1:8766/`. Для zoom/capture закреплён тот же адрес. Используется уже доступный runtime Playwright, установка зависимостей не нужна.

Отчёты `package-*-qa.json` содержат хеши проверенного исходного состояния. `selected-*-qa.json` относятся к предыдущему показу. Не подменять assertions или сравнивать новый интерфейс со старой картинкой ради PASS.

Автоматическая политика отклонила рекурсивное удаление двух вспомогательных браузерных профилей с причиной `blocked by policy`. Повторных попыток удаления нет; профили остаются в TEMP. HTML/PNG-резервы проекта не удалялись.

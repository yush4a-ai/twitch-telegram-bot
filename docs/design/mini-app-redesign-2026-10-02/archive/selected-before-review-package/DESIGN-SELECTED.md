# Мини-апп: выбранный А «Собранный»

02.10.2026. Направление выбрано владельцем. Доработанный дизайн ожидает визуальной приёмки. Сейчас изменён только отдельный предпросмотр; перенос в приложение ещё не начат.

## Общие правила

Светло-серый фон, общие белые поверхности, компактные строки и разделители, графитовый текст, один синий акцент. Системный шрифт с кириллицей. Боковой отступ 16 px, аватар 44 px, действия не ниже 44 px, основная кнопка 48 px. Нет декоративного стекла, градиентов и рамки телефона.

Первый вход — светлая тема. В профиле: «Светлая», «Тёмная», «Как в Telegram». Явный выбор сохраняется; только третий вариант следует окружению. В макете окружение имитируется, в продукте нужны события настоящего Telegram SDK.

## Стримеры

Строки из А, группировка из Б. «В эфире» и «Не в эфире» имеют счётчики по показанным строкам. «Нет свежих данных» — отдельная группа; пауза уведомлений — отдельная подпись. Обновление, возврат из деталей и переключение доступных вкладок сохраняют прокрутку.

Имя занимает до двух строк с многоточием; вся строка открывает детали с полным именем. Аватар соответствует аккаунту; без изображения — буква или нейтральный значок. В макете публичные картинки используются только для Twitch и Monstercat; длинные имена и состояния условные.

«Поиск по моим стримерам» фильтрует подписки. «Добавить» открывает поиск нового канала. В пустом списке поле «Ник или ссылка Twitch» видно сразу. Поиск и добавление — два явных действия; ошибка сохраняет ввод. Папки и выбор видеопревью имеют отдельные входы. Счётчик видео включает offline. Free показывает фото; сохранённые настройки Plus не удаляются.

## Telegram-канал

Новые подключения — только каналы; старые группы сохраняются. На каждом шаге одна инструкция по состоянию:

| Состояние | Следующее действие |
|---|---|
| Бота нет | Добавить @TwitchSignalTestbot в администраторы, разрешить публикацию |
| Бот участник | Назначить администратором, разрешить публикацию |
| Бот администратор без права | Включить только «Публикация сообщений» |
| Права проверены | Подтверждение → пример поста → отдельное включение публикаций |
| Ошибка связи | Сохранить выбранный канал, повторить проверку без ложного успеха |

Встроенный выбор и переход через переписку дают видимый результат. Для переписки: объяснение → видимая кнопка выбора → возврат на прежний шаг. Отмена и устаревший запрос не требуют повторного подключения Twitch. В макете оба пути — обозначенные локальные примеры, сообщения не отправляются.

После Twitch: успех с аккаунтом и кнопкой возврата, ошибка, отмена. Будущий продукт подтверждает результат сервером, не параметром URL. Реальный OAuth здесь не выполняется.

## Профиль

Основной экран: план, состояние, срок и полезные счётчики. Возможности и собственные операции находятся внутри «Управление подпиской». Viewer Plus и Streamer Plus разделены. Технические подтверждения/отзыв/заказы предназначены отдельному защищённому инструменту владельца с серверной проверкой.

«Итоги эфиров» содержит прежний HTML-экспорт. Генератор, бесплатные права, цены и правила доступа не меняются. Предпросмотр показывает вход, а не создаёт новую аналитику.

## Мобильное окружение и границы

Показаны видимые области 390×844 с прокручиваемым содержимым и нижним меню; длинные снимки сохранены отдельно. Системные панели и «Назад» Telegram не рисуются. При переносе нужны реальные SDK safe areas, viewport/клавиатура и BackButton. Постоянная кнопка «Приложение» сохраняется вместе с обычным доступом к главному меню.

Проверены Chromium и WebKit: 360/390/430/768/1440 px, светлая/тёмная темы; в Chromium также увеличенный текст, 200 строк, поиск/ошибка/повтор, ввод, прокрутка/возврат и состояния подключения. Сокращённая высота 440 px — только приближение клавиатуры. Настоящие Telegram, SDK, OAuth, клавиатура, серверные права и отправки — **NOT TESTED**.

При переносе отдельно сверить минимальные права с `bot/streamer_community.py` и действиями `bot/live_post.py`: текущая проверка дополнительно требует `can_edit_messages`. На этом этапе проверка не изменена. Нужны фактические display names/аватары и свежесть наблюдения в данных, защищённый инструмент владельца и сохранение всех существующих функций: Free 50 / Plus 200, пять видео, фильтры, категории, напоминания, папки, история и оформление постов.

Следующий шаг после визуальной приёмки — последовательный план переноса на все экраны. Реализация начинается после отдельного утверждения плана, только для @TwitchSignalTestbot.

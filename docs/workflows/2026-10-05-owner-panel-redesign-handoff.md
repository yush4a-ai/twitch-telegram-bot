Что стоит знать про чат:

- сообщения появляются в панели сами, обновлять страницу не нужно;
- Enter отправляет ответ, Shift+Enter переносит строку;
- видны текст, картинки, стикеры, гифки, видео, видеокружки, голосовые, файлы, контакты, геолокация;
- в списке есть все, кто запускал бота, даже без единого сообщения, — можно написать первым;
- причина «невидимых» сообщений найдена и устранена: приём был внутренним слоем, а такие слои библиотека вызывает только при совпадении с обработчиком, поэтому обычный текст пропускался.

## Как посмотреть

**Живая панель в рабочем контуре:** `https://worker-production-cee5.up.railway.app/admin` — вход владельца через Telegram. Там сейчас старая версия панели: редизайн в рабочий контур ещё не выпускался.

**Локально, без боевых данных:** фиктивный сервер отдаёт выдуманные данные и слушает только `127.0.0.1`.

```
.venv\Scripts\python.exe scripts/admin_ui_fixture.py --port 8791
```

Затем открыть в браузере `http://127.0.0.1:8791/admin`. Экраны: `#/overview`, `#/users`, `#/access`, `#/system`, `#/growth`, `#/payments`.

**Узкие ширины:** `docs/design/admin-redesign-2026-10-05/panel-frame.html` — рамка с iframe 360 и 390 px (headless Chrome не умеет окно уже 500 px).

**Снимки:** `docs/design/admin-redesign-2026-10-05/screenshots/impl/` — обзор, люди, доступы, система, рост, оплаты, адаптив 768 и 1440, узкие ширины.

## Что проверить руками (чеклист)

1. Обзор: показатели читаются, «Требует внимания» и «Последние события» справа, быстрые действия ведут в «Люди», «Доступы», «Систему».
2. Люди: поиск по имени, `@username`, ID и Twitch; карточка человека открывается справа; у человека без Twitch — «Не подключён», без активности — «Нет данных».
3. Доступы: три вкладки, переключение мышью и стрелками, «Истекающие» показывает права ближайшей недели.
4. Система: шесть строк, у каждой состояние словом и знаком, время наблюдения в шапке; копия без проверки — «Не проверена».
5. Рост: воронка «пришли по ссылке → открыли бота → добавили канал → получили Plus» с долями, ниже — общая картина по людям без ссылки. Оплаты: честная заглушка, ни одной кнопки, создающей платёж.
6. Рассылки → «Кампании»: форма сообщения (текст, необязательная кнопка, необязательная картинка), расчёт аудитории до отправки, список кампаний с прогрессом и остановкой, отписавшиеся с возвратом.
7. Рассылки → «Чат»: список диалогов с непрочитанными, переписка, ответ (текст или картинка) и удаление переписки.
8. Телефон: нижняя навигация «Обзор / Люди / Доступы / Рассылки / Ещё», ничего не перекрыто, горизонтальной прокрутки нет.
9. Клавиатура: видимый фокус, вкладки стрелками, Escape закрывает диалоги, фокус возвращается в кнопку.

## Что проверено и чем

- Полный прогон проекта: **1908 passed, 3795 subtests**, 8 падений — известные ограничения среды (тестам нужны временные файлы вне проекта). Раздел рассылок и чата покрыт отдельно: данные, API, отправитель, приём сообщений, картинки, оповещения, воронка.

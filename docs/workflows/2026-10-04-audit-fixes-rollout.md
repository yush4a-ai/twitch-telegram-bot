## Что именно убирает первый фикс (замер на живых данных)

- из 59 отслеживаемых каналов user-токен есть только у 2 — остальные 57

- в аудите это дало **111 traceback'ов за 4 минуты**; после фикса таких записей
  не будет вовсе;
- ошибки по-прежнему видны, если сбой настоящий (`logger.exception` сохранён).

## Почему перезапуск не создаёт сообщений

В аудите на рабочем контуре оставались 4 подписки в состоянии «эфир идёт,
пост не опубликован». Проверено на данных: у этих чатов всего 4–8 подписок,
то есть лимит тарифа (50/200) ни при чём; ветка обработки определяется полями
`same_stream`/`reconnect`, которые целиком читаются из базы
(`is_live`, `last_stream_id`, `offline_since`, `stats_sent`). Перезапуск эти
поля не меняет (`invalidate_live_follow_counts_after_restart` трогает только
надёжность счётчика фолловеров), поэтому решение об отправке остаётся тем же,
что и в текущем цикле — то есть сообщений не появится.

## Порядок выкладки

1. **Проверить тишину в эфире.** Перед каждым шагом убедиться, что нет подписок
   в состоянии «эфир идёт, пост не опубликован»:
   `SELECT COUNT(*) FROM tracked_channels WHERE is_live=1 AND last_message_id IS NULL AND notify_enabled=1`
   должно быть 0. Иначе перезапуск может опубликовать тихую карточку о текущем
   эфире (без звука, но сообщение появится).
2. **Тестовый контур** (`@TwitchSignalTestbot`, Railway staging): guarded deploy
   из ветки фиксов.
3. **Проверки после тестового контура:** `getMe` возвращает тестового бота;
   `/healthz` 200; в журнале больше нет traceback'ов `TwitchAuthError`; в
   `/data/backups` появился свежий `auto-*.db`; нет повторяющихся предупреждений
   «bot was blocked by the user»; панель владельца в блоке резервных копий
   показывает этот же файл (`last_backup_name`) — панель уже читает каталог
   `backups` с префиксом `auto-` и retention 5, то есть формат копий совпадает.
4. **Рабочий контур** — только после отдельного разрешения владельца: слияние
   фиксов в `main` (production собирается из GitHub `main`) и deploy.
5. **Проверки после рабочего контура:** те же плюс `getMe` = `@TwitchSignalBot`,
   платежи OFF, `integrity ok`, размер и свежесть копии.

## Известные ограничения

- Пять тестов `tests/test_production_admission.py` в текущей среде не
  выполняются: им нужен файл контракта **вне** каталога проекта, а песочница
  разрешает запись только внутри. Перед production их следует прогнать на
  обычной сборочной машине.
- Второй исполнитель (переделка админ-панели) держит незакоммиченные правки в
  `bot/admin_ui/*`; поэтому выкладка идёт из отдельной ветки, а не из общей
  `autonomous/twitchsignal-roadmap`.
